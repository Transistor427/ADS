# ADS — Auto Diagnostic System

Расширение Klipper для автоматической диагностики 3D-принтера.

Команда `AUTO_DIAGNOSTIC` последовательно проверяет:

1. **Нагреватели** — стол, экструдер и (опционально) камеру
2. **Парковку осей** — `G28`
3. **Вентилятор обдува** — по падению температуры сопла
4. **Выравнивание стола** — `G34` и `G29` (если парковка прошла успешно)

По завершении в консоль выводится отчёт по каждому шагу. Нагреватели и вентилятор отключаются автоматически.

## Установка

Одной командой (ветка `v2`):

```bash
git clone -b v2 https://github.com/Transistor427/ADS.git ~/ADS && ln -sf ~/ADS/auto_diagnostic_system.py ~/klipper/klippy/extras/auto_diagnostic_system.py && ln -sf ~/ADS/auto_diagnostic_system.cfg ~/printer_data/config/auto_diagnostic_system.cfg
```

Добавьте в `printer.cfg`:

```ini
[include auto_diagnostic_system.cfg]
```

Подставьте свои температуры и координаты в `auto_diagnostic_system.cfg`, затем перезапустите Klipper:

```bash
sudo systemctl restart klipper
```

## Конфигурация

| Параметр | По умолчанию | Описание |
|---|---|---|
| `extruder_temp` | `200.0` | Целевая температура экструдера (°C) |
| `bed_temp` | `60.0` | Целевая температура стола (°C), `0` — пропустить |
| `chamber_temp` | `0.0` | Температура камеры (°C), `0` — пропустить |
| `park_x` / `park_y` / `park_z` | `100` / `100` / `10` | Позиция для проверки вентилятора |
| `fan_temp_drop` | `2.0` | Минимальное падение температуры для успешной проверки (°C) |
| `fan_check_time` | `15.0` | Время замера падения температуры (сек) |
| `stabilization_time` | `5.0` | Пауза стабилизации перед проверкой вентилятора (сек) |

## Использование

В консоли Klipper / Mainsail / Fluidd:

```
AUTO_DIAGNOSTIC
```

## Требования

- Klipper с модулями нагревателей и кинематики
- Для выравнивания — настроенные `G34` / `G29` (например, через макросы)
- Вентилятор обдува, управляемый через `M106`
